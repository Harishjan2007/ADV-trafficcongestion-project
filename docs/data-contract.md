# Canonical Data Contract: Chennai Traffic Intelligence Platform

**Date:** 2026-08-30  
**Status:** Approved Specification (Phase 0)

---

## 1. Overview & Data Tiering

To enable integration of heterogeneous Chennai datasets (sensor feeds, police accident logs, IMD weather feeds, OpenStreetMap GIS vectors, and ML predictions) without altering frontend components, all internal data flows MUST adhere strictly to the **Canonical Data Contract**.

Data is strictly categorized into 4 operational states:
- `OBSERVED`: Ground-truth values collected from sensors/logs.
- `DERIVED`: Computed metrics based on explicit mathematical formulas.
- `PREDICTED`: Values generated by external ML inference models.
- `SIMULATED`: Synthetic development data (strictly watermarked in UI).

## 3. Mathematical Formulas for Derived Metrics

### A. Traffic Utilization ($U$)
$$U = \frac{\text{vehicle\_count}}{\text{road\_capacity}}$$

### B. Speed Reduction / Deficit ($R_v$)
$$R_v = \max\left(0, \frac{\text{speed\_limit} - \text{average\_speed}}{\text{speed\_limit}}\right)$$

### C. Congestion Index ($CI$)
A standardized composite index normalized to $[0, 100]$:
$$CI = \min\left(100.0, \, \left(0.45 \cdot \min(U, 1.5) \cdot \frac{100}{1.5} + 0.55 \cdot R_v \cdot 100\right)\right)$$

### D. Congestion Level Mapping
- **`Low`** (Green, `#10B981`): $0 \le CI < 30$
- **`Moderate`** (Yellow, `#F59E0B`): $30 \le CI < 55$
- **`High`** (Orange, `#F97316`): $55 \le CI < 75$
- **`Severe`** (Red, `#EF4444`): $75 \le CI \le 100$

### E. Decision Support Priority Score ($PS$)
$$PS = \min\left(100.0, \, \left(0.50 \cdot CI + 0.25 \cdot \min(100, \text{accident\_count} \times 40) + 0.25 \cdot (\text{is\_peak\_hour} ? 25 : 0)\right)\right)$$
- **`Critical`**: $PS \ge 80$ OR ($CI \ge 75$ AND $\text{accident\_count} \ge 1$)
- **`High`**: $60 \le PS < 80$
- **`Medium`**: $35 \le PS < 60$
- **`Low`**: $PS < 35$

## 4. Null & Missing Data Policy

- Missing **`weather_condition`** $\rightarrow$ Return `null`, UI displays `"Weather Data Unavailable"`.
- Missing **`accident_count`** $\rightarrow$ Default to `0`, UI does not render accident marker.
- Missing **`road_capacity`** $\rightarrow$ Impute based on `road_type` standard defaults (`Arterial`: 3600 veh/hr, `Sub-Arterial`: 2400 veh/hr, `Expressway`: 5000 veh/hr).
- Missing **`speed_limit`** $\rightarrow$ Default to `50.0 km/h` (Chennai municipal arterial default).
