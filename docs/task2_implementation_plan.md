# TASK 2: MULTI-CITY TRAFFIC INTELLIGENCE PLATFORM
## Technical Architecture & Implementation Specification

### 1. Scope & Objective
Extend the Chennai Traffic Intelligence Platform to support:
1. Chennai
2. Vellore
3. Coimbatore

Features:
- Dynamic multi-city switching across Map, Leaderboard, Analytics, Clustering, Accident Profiling, and ML Forecasting.
- Dedicated City Comparison view with cross-city aggregations, hourly curves, box plots, accident comparisons, multi-horizon progression, model benchmarks, and cross-city heatmaps.
- Complete data provenance labeling (`OBSERVED`, `DERIVED`, `PREDICTED`, `SIMULATED BENCHMARK DATA`).
- 100% backward compatibility for all 35 Task 1 tests.
